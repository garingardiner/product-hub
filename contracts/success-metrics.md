# Contract: Success Metrics (phase 3, defined; phase 5, reviewed)

**Purpose:** Decide in advance how we'll know this worked, then check after launch.
**Consumers:** PM, leadership; later a dashboard.
**Default form:** `data` (`metrics.yaml`). Render into the spec or a dashboard as needed.

## Must contain (per metric)
- Name, type (leading / lagging), target, stretch target
- Measurement method: tool, query or definition, time window
- Review date (e.g. 30 days post-launch)
- After launch: actual value and verdict (hit / missed / inconclusive)

## Approved when
Every metric has a target, a method, and a review date.
